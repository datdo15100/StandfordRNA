# Frozen V4 Kaggle external check

This private Kaggle notebook deploys the scientific method frozen at commit
`4ea1044cca5e2ebcb5e1b76ab02d955e84d21758`. It produces five native-blind
structures per target using the retained Thesis TBM bank, two direct DRfold2
candidates when resources permit, and Selected Geometry. Missing pretrained
slots use the next template candidates.

The score is whole-pipeline external evidence only. It is not used to attribute
the H1, H2 or H3 component effects, which come from the controlled 97-target
confirmatory evaluation.
